# 🎁 AgaBe Personalizados

Site institucional e vitrine de produtos da **AgaBe Personalizados**, loja de Pirassununga/SP que produz chaveiros, canecas, quadros, relógios e muito mais, tudo **personalizado com fotos e nomes**.

O projeto apresenta a loja, mostra os produtos disponíveis e facilita o contato do cliente para fazer o pedido.

---

## 📋 Sobre o projeto

A AgaBe Personalizados transforma memórias em presentes. Este site foi criado para:

- Apresentar a marca e seus produtos de forma atrativa;
- Mostrar o catálogo de itens personalizáveis;
- Facilitar o contato direto com os clientes;
- Funcionar bem em qualquer dispositivo, principalmente no **celular**, onde a maior parte dos clientes acessa.

## 🛍️ Produtos

- Chaveiros personalizados
- Canecas personalizadas
- Quadros personalizados
- Relógios personalizados
- E outros itens sob encomenda

Todos os produtos podem ser personalizados com **fotos** e **nomes**.

## ✨ Funcionalidades

- Layout **responsivo**, adaptado para celulares, tablets e desktops
- Seção de produtos organizada em **grid**, com imagem em destaque e descrição abaixo
- Seção de contato para o cliente fazer seu pedido
- Navegação simples e intuitiva
- Interações com JavaScript

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso |
|------------|-----|
| **HTML5** | Estrutura e semântica das páginas |
| **CSS3** | Estilização, Grid, Flexbox e responsividade (media queries) |
| **JavaScript** | Interatividade do site |

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/seu-usuario/agabe-personalizados.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd agabe-personalizados
   ```

3. Abra o arquivo `index.html` no navegador.

   Se preferir, use a extensão **Live Server** do VS Code para ver as alterações em tempo real.

## 📱 Responsividade

O site foi desenvolvido com abordagem voltada para dispositivos móveis, usando **media queries** para ajustar o layout em diferentes tamanhos de tela, garantindo uma boa experiência de navegação no celular.
